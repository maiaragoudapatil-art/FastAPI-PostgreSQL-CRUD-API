# FastAPI PostgreSQL CRUD API

A RESTful API project built using **FastAPI** and **PostgreSQL** with **psycopg2**. This project demonstrates how to connect a FastAPI application with a PostgreSQL database and perform database operations through HTTP APIs.

##  Features

- FastAPI and PostgreSQL integration
- PostgreSQL database connectivity using psycopg2
- CRUD operations
- GET, POST, PUT, and DELETE APIs
- Path parameters
- Query parameters
- Pydantic models for request validation
- Exception handling
- Swagger API documentation
- ReDoc API documentation
- API testing with Postman

##  Technologies Used

- Python
- FastAPI
- PostgreSQL
- psycopg2
- Pydantic
- Uvicorn
- Postman

##  Project Flow

Client / Postman
        ↓
FastAPI
        ↓
Pydantic Validation
        ↓
CRUD API
        ↓
psycopg2
        ↓
PostgreSQL

##  Purpose

The purpose of this project is to understand how backend APIs communicate with a relational database and how CRUD operations can be implemented using FastAPI and PostgreSQL.
